# Prismium

**Vanilla+ performance optimization for Minecraft.**

Prismium is a lightweight client-side performance mod focused on configurable rendering optimizations while keeping the vanilla Minecraft experience intact.

## Features

- **Entity Culling** — prevents entities outside the camera view from being rendered.
- **Distant Culling** — controls how far away entities are rendered.
- **Particle Culling** — prevents distant particles from being rendered.
- **Particle Distance** — controls the maximum render distance for particles.
- **Dropped Item Distance** — independently controls how far dropped items are rendered.
- **Persistent Configuration** — Prismium settings are stored in `.minecraft/config/prismium.json`.
- **Configurable Settings** — press **G** by default to open Prismium Settings.
- **Custom Keybind** — change the Prismium Settings key in Minecraft's Controls menu.
- **Mod Menu Support** — open Prismium Settings directly from Mod Menu.

## Development

Prismium is currently in **Beta** and is actively being developed.

More performance optimizations, culling options and configuration features are planned for future releases.
